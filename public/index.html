Read Me

Hi, I'm Marcel.

Online I go by m5rcel. I'm a full-stack and systems developer from Poland, and I like websites, APIs, Linux, self-hosting, Minecraft, Roblox and old internet pages.

I build things from scratch: chat platforms, Twitter recreations, a programming language, package managers, a couple of kernels and plenty of small tools. Most of it lives on GitHub as wypiek, and some of it runs on my own servers.

It's in Warsaw right now.

Currently baking

  • meowcord, a self-hosted Discord clone with message encryption and federation, together with tiago.
  • AXON, a statically typed language that compiles to C11.
  • m3, a Wayland compositor in Rust with a Material 3 Expressive look.

House recipe

Start simple. Make it work. Keep it light. Give it character.

And if it breaks, call it an experimental batch.
